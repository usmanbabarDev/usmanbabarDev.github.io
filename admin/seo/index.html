      Writing checklist

      Every post

      • Title like the search: "Is Haribo Halal in the UK?" (30–60 characters).
      • Description 110–158 characters that answers the question.
      • First paragraph gives the short answer — Google uses it for the answer box.
      • At least 3 subheadings (##) and 400+ words.
      • 3+ internal links to answers, E-numbers, ingredients or the checker.
      • A photo you are allowed to use, with a description and credit.
      • Present scholars' views fairly; never write a fatwa. Cite sources.

      Every week

      • Publish 1–2 posts from the topic ideas above.
      • Fix the lowest-scoring post in the table.
      • In Search Console, improve pages ranking 11–20 (page 2).
      • Answer correction emails within 2 days.
      • Share each new post once in a community group.

      Team access

      1. The owner adds the teammate to the private GitHub repository usmanbabarDev/halalverdict (Settings → Collaborators → Add people, role: Write).
      2. The teammate creates a GitHub token: GitHub → Settings → Developer settings → Fine-grained tokens → repository halalverdict → Contents: Read and write.
      3. Open the blog editor → Sign In Using Access Token → paste the token. Never share tokens; remove access when someone leaves.
